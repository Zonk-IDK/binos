# BinOS Website

A responsive, Apple-inspired landing page for the BinOS Seagull project.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Customize
- Replace the abstract hero artwork in `index.html` with one of your own landscape photos.
- Replace the placeholder GitHub URL with the real BinOS repository.
- Update the roadmap as development progresses.

## Deploy free
A simple static site can be hosted on GitHub Pages, Cloudflare Pages, or Netlify. You can start with a free provider subdomain and connect a custom domain later.

## Note
BinOS is an independent project concept. Arch Linux and Pantheon are separate projects with their own trademarks and licenses.
